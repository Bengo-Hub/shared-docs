# Internal material

Operational runbooks, the platform gap analysis, business and pricing documents and internal
history are kept in the private `codevertex-private-docs` repository, under `shared-docs-internal/`.

This repository is public. Add nothing here that names production hosts, IP addresses, cluster
namespaces, database users, credentials, tenant identifiers, KRA PINs or device serials, or that
describes an unfixed weakness. Put that material in the private repository.
