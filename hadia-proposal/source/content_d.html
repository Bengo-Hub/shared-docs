Repository access

The hadia-ui and hadia-api repositories are created in a GitHub organisation owned by Hadia, with Codevertex as a contributor. Hadia has read access from day one and full administrative control at handover. Codevertex platform repositories remain private to Codevertex.

Platform licence

Hadia receives a non-exclusive, non-transferable licence to use the Codevertex platform services for the duration of the service agreement, included in the monthly service fee. Hadia's own developers, or another vendor appointed by Hadia, may use the documented platform APIs with API keys issued to Hadia.

Appointing another developer

Hadia may appoint another developer at any time to maintain or extend hadia-ui and hadia-api. Codevertex provides API documentation, environment access for Hadia's appointed developer and a handover session. The platform services continue to be operated by Codevertex while the service agreement is in force.
